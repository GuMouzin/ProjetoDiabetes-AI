# 🩺 Predição de Diagnóstico de Diabetes com Deep Learning

Modelo de Rede Neural Profunda (Deep Learning) desenvolvido em Python utilizando **TensorFlow/Keras** para realizar a predição de diagnósticos de diabetes com base em dados clínicos tabulares.

---

## 🚀 Tecnologias Utilizadas
* **Linguagem:** Python 3.10+
* **Manipulação de Dados:** Pandas, Scikit-Learn
* **Deep Learning:** TensorFlow / Keras (Sequential API, Dense Layers, Dropout, Early Stopping)
* **Visualização:** Matplotlib
